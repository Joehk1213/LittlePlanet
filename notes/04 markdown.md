# 🚀 實體網店：全渠道自動化電商營運架構藍圖

> **核心目標**：建立以 **Supabase** 為中央心臟（Single Source of Truth），透過半自動化輸入與 **n8n** 自動化引擎，實現「一處中央輸入，全渠道（WhatsApp / Signal / FB / IG / 官網）同步發布」的無縫電商生態，徹底解決排版跑版、Emoji 變形、圖片對應繁瑣及多平台手動出 Post 的痛點。

---

## 一、 現階段痛點與核心共識

### 1. 過去手動營運的四大痛點

* **Excel 中轉失效**：直接複製貼上 WhatsApp 豐富排版與彩色 Emoji（如 `✅`、`💰`）到 Excel 會導致編碼變形（變成黑白符號或亂碼），換行也會被拆散。
* **圖文對應極度繁瑣**：手動下載圖片、命名並拉進 Excel 儲存格或手動配對極耗時間。
* **各平台格式需求不一**：WhatsApp 需要原汁原味的排版與直覺價格標示；而 IG/FB 則需要額外加上 Hashtags 與引導連結。
* **重複勞動**：同一個商品需要在 WhatsApp、IG、FB、Signal 分別複製貼上發布 4 次以上，效率極低。

### 2. 確立的技術共識

* **中央資料庫 (Master Database)**：採用 **Supabase** 作為全店商品與文案的單一真理來源。
* **文案格式**：放棄純 Excel 編輯，改用 **UTF-8 純文字 (`.txt`)** 或結構化中央表單輸入，確保 100% 完美保留彩色 Emoji 與原始換行排版。
* **圖片管理**：圖片直接上傳至 **Supabase Storage (圖床)**，由資料庫以 URL 形式集中調用。

## 三、 標準化營運工作流程 (Workflow SOP)

### 階段一：中央上架 (Single Point of Entry)

店主從供應商/買手處取得商品實拍圖與簡短規格後，在中央管理介面（或 Supabase 表單）進行一次性輸入：

1. **圖片上傳**：上傳 1~3 張高畫質實拍圖至 Supabase Storage，自動產生公開圖床 URL。
2. **基本欄位填寫**：
* `name` (商品名稱)
* `price` (售價)
* `category` (商品分類：如美味零食、家居生活、飲品特選)
* `deadline` (截單日期：如 `10月21截單`)
* `status` (發布狀態：`draft` 草稿 / `published` 已上架)


3. **詳細文案 (Description)**：直接貼上帶有完整 Emoji (`✅`、`💰`) 與原始換行排版的宣傳文案。

### 階段二：網店即時同步 (Supabase Web Store)

* 當狀態改為 `published`，Supabase 資料庫即時更新，前端網店自動上架該商品，買家可直接瀏覽與下單。

### 階段三：n8n 自動化多平台分發 (Omnichannel Distribution)

透過 n8n 監聽 Supabase 的 Webhook，觸發以下自動化分支：

1. **即時通訊分發 (WhatsApp / Signal)**：
* 自動抓取原始文案（保留完整 Emoji 與排版）與主圖，透過 API 發送至指定的「清貨/連線群組」。


2. **社群媒體分發 (Facebook / Instagram)**：
* **格式適配**：透過 n8n 內建的 JavaScript 或 AI 模組，自動在文案尾端補上對應平台的 Hashtags（如 `#日本代購`）與導購連結。
* **API 發布**：呼叫 Meta Graph API 自動發布貼文至 FB 專頁與 IG。


3. **截單日倒數提醒 (Deadline Automation)**：
* 設定 n8n Cron 定時排程，當距離 `deadline` 剩餘 24 小時，自動發送限時促銷提醒至通訊群組。

## 四、 實施建議與防呆機制

1. **引入狀態控制 (`status`)**：
* 商品上架前必須設為 `draft`（草稿），避免填寫中途因誤觸發布而導致半製成文案外流。


2. **圖文備份機制 (Master Excel / txt)**：
* 歷史宣傳文案保留一份備份於 `.txt` 檔或透過腳本匯入，作為日後快速迭代或系統重建的資料底座。


3. **分階段推進**：
* **Phase 1**：穩固 Supabase 結構與網店前台的商品呈現（當前進度）。
* **Phase 2**：建立簡易的中央輸入介面與圖片上傳流程。
* **Phase 3**：導入 n8n 串接 API，正式實現一鍵多平台廣播。
