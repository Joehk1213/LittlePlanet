# 🪐 LittlePlanet 宇宙網店 · 系統升級與建置總結報告

## 一、 🛒 前台核心、購物車與微交互體驗 (UI/UX Micro-interactions)

* **側滑抽屜購物車 (Cart Drawer)**：支援多商品選擇、動態數量加減與側滑抽屜介面，加購時商品圖標自動連動，並附帶動態數字彈跳（Bounce）動畫。
* **全局 Toast 浮動提示**：全面取代瀏覽器原生的阻斷式 `alert()`，操作成功或錯誤時在頂部顯示 2 秒自動淡出的精緻 Toast 提示。
* **全站骨架屏 (Skeleton Screens)**：前台商品載入及後台資料 Fetch 時，全面採用灰色閃爍骨架屏過渡，消除空白與畫面跳動。
* **高效能即時搜尋**：支援 140ms 即時過濾（Instant Search），並附帶熱門關鍵字標籤（如 `#日本直送`、`#限時特價`）快速篩選。
* **氛圍感與防呆徽章**：庫存少於 5 件自動顯示 `🔥 僅剩最後 X 件！` 緊張感標籤，團購商品自動附帶階梯價與優惠標籤。
* **同裝置熟客記憶**：透過瀏覽器安全地記憶常用電話、姓名與取貨地址（順豐站/智能櫃代碼輔助），實現一鍵快速回購，未提供直接外洩個資的公開 API。

## 二、 👥 團購階梯價、真實評價與深鏈結開單 (Advanced Commercial Features)

* **團購階梯價 (Tiered Bulk Pricing)**：支援伺服器端核算價格（防止前端竄改），買滿指定數量自動套用優惠。
* **商品真實評價與審核機制**：
* 新增 `reviews` 資料表與評價審核流程。
* 買家透過查單頁（電話 + 正式單號雙重驗證）完成交易後可提交 1-5 星評價。
* 後台提供專屬審核分頁，審核通過後才在前台商品頁公開展示平均星級與留言。


* **WhatsApp / DM 專屬開單連結 (Deep-Link Order Generation)**：
* 支援解析帶有參數的網址（如 `/?items=51:2&phone=...`）。
* 客戶點擊後自動將商品加入購物車並預填聯絡資料。
* 後台提供「一鍵生成開單連結」工具，大幅提升私訊聊天促單效率。

## 三、 📊 進階營運利潤分析與流動端 PWA 支援 (Analytics & PWA)

* **毛利與成本追蹤儀表板**：
* 支援商品成本價 (`cost_price`) 管理。
* 提供指定期間內的總營收、總成本、毛利率、淨利潤排行分析。

* **流動端 PWA (Progressive App Experience)**：
* 建立 `manifest.json` 與高畫質 192px / 512px 應用圖示，支援手機一鍵「加入主畫面」。
* 註冊 Service Worker 支援靜態殼層快取，並主動排除 API 請求與帶有個人參數的開單連結，確保資料絕對隱私。

## 四、 📱 半自動 SOP 貼文與商品快速生成器 (SOP Post Generator)

* **隱私防呆設計**：店主貼上的供應商批發原文僅留在瀏覽器本機對照，絕不提交或對外公開作商品描述。
* **智慧價格與日期計算**：輸入批發價後自動計算 1.2 倍預設零售價（可手動微調），並預設 7 天後的截單時間。
* **品牌範本與即時預覽**：自動套用公司專屬抬頭（🪐《LittlePlanet 宇宙直送》）、彩色 Emoji、分隔線與開單直達短網址，右側設有 WhatsApp 樣式實時預覽框。
* **一鍵上架與複製文案**：支援上傳符合安全規範的商品圖片（限制 5MB、格式及簽章驗證），點擊即可一鍵同步建立資料庫商品，或一鍵複製廣播文案發至群組。

## 五、 📦 5 大智慧營運與供應鏈管理功能 (ERP-Level Smart Features)

* 手動修改庫存時強制要求填寫原因（如損毀、員工自用、盤點差異），並寫入專屬稽核記錄表。
