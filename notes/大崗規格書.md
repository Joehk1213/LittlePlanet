 

# 🌌 LittlePlanet 宇宙網店 — 專案全方位深度統合報告 (Comprehensive Project Specification)

## 1. 專案核心定位與背景 (Project Overview)

- **專案名稱**：LittlePlanet 宇宙網店（Little Planet 小行星）
    
      
    
- **業務性質**：網上零售現貨商店，涵蓋日本藥妝、保健品、韓國美妝及環球零食等多元化熱門商品。
    
      
    
- **系統目標**：提供消費者流暢的購物體驗與即時訂單追蹤，同時賦予店主高效的後台管理、庫存更新與銷售數據分析能力。

## 3. 系統技術棧 (Technology Stack)

- **後端核心**：Node.js (建議 v22 或以上版本) + Express 4 網頁框架。
    
      
    
- **資料庫與身份驗證**：Supabase (`@supabase/supabase-js`) 提供高穩定性資料儲存與安全驗證。
    
      
    
- **前端呈現**：原生 HTML5 / CSS3 / JavaScript，確保極佳的載入效能與跨裝置相容性。
    
      
    
- **數據視覺化**：整合 Chart.js 庫於後台展示銷售趨勢。

## 5. 核心模組功能細節 (Module Specifications)

### A. 前台商城 (`public/index.html`)

- **商品目錄展示**：
    
      
    - **日本藥妝與保健**：如胃藥錠、小林製藥喉嚨痛沖劑、EVE 止痛藥（銀色/金色）、SS製藥化痰止咳藥、小林製藥祛疤膏、IHADA 暗瘡膏、Elixir 防曬底霜、NMN 粉底、J-iromise 夜酵素 EX、蟲草大王 Cs4 等。
        
          
        
    - **美妝保養與生機食品**：韓國 TENZERO 補濕面霜、Lactofit 鍾根堂益生菌、BB LAB 零糖膠原蛋白軟糖、蘋果醋軟糖、Glam.D 代餐奶昔（伯爵茶味、忌廉曲奇味、豆奶味）。
        
          
        
    - **環球零食與即時麵**：皇冠牌 12 頭鮑魚、年輪蛋糕、Glico 乳酸菌餅乾、Sanrio 水果軟糖、Mathez 法式松露朱古力、白鍾元秘方白拉麵、MAMA 亞洲系列即食麵（卡邦尼、黑松露、麻辣肉味、打拋豬肉杯麵）、檳城白咖喱麵、TEAZEN 康普茶等。
        
          
        
- **互動購物車**：支援商品數量增減、小計自動計算、收件資訊填寫與一站式送出訂單。
    
      
    
- **頁首/頁尾 社群連結**：前台直連 Facebook 粉專與 IG 官方頁面，方便顧客隨時追蹤最新上架商品與活動。
    
      
    

### B. 訂單追蹤系統 (`public/track.html`)

- 供顧客隨時輸入訂單號碼，即時查詢訂單最新狀態（如：備貨中、已發貨、已完成、物流追蹤碼對應）。
    
      
    

### C. 營運管理後台 (`public/admin.html`)

- **安全登入**：透過後端 `admin-sessions.js` 驗證，阻擋未授權存取。
    
      
    
- **商品管理**：支援後台新增、修改、上下架商品及庫存即時調整。
    
      
    
- **訂單管理**：列表化檢視所有進單，並可一鍵更新訂單狀態。
    
      
    
- **數據儀表板**：結合 Chart.js 直觀呈現營業額與熱銷商品統計。
    
      
    

### D. 系統安全防禦機制 (`middleware/`)

- **Helmet 安全標頭**：防止跨站腳本攻擊 (XSS) 及點擊劫持。
    
      
    
- **Rate Limiting 速率限制**：針對結帳、登入與查詢等高頻路由進行流速控制，防止 DDoS 攻擊。
    
      
    
- **集中式錯誤捕捉 (`error-handler.js`)**：確保伺服器遇到異常時不會直接當機，並向前端輸出安全規範內的錯誤訊息。
    
      
    

## 6. 開發與部署維護指南 (Development & Maintenance)

### 本地測試與啟動指令

於專案根目錄執行以下指令：

  

PowerShell

```
# 1. 安裝所有相依套件
npm ci

# 2. 檢查主程式語法
node --check index.js

# 3. 執行測試
npm test

# 4. 啟動本地開發伺服器
npm start
```

- **健康檢查點**：伺服器啟動後可訪問 `http://localhost:3000/health` 確認狀態是否回傳 `status: "ok"`。
    
      
    

### 生產環境部署

- 詳細的雲端主機對接、Supabase 環境變數設定（`SUPABASE_URL`, `SUPABASE_ANON_KEY` 等）及資料庫 Schema 遷移步驟，請參閱專案根目錄中的 **`DEPLOYMENT.md`** 檔案。
