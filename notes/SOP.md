## 📋 新商品上架 4 步 Standard Procedure (SOP)

### 步驟 1：準備相片（Save 相片與命名規則）

1. **儲存相片**：從供應商/買手/WhatsApp 下載商品照片，統一放進你電腦的 `import_use/image/` 資料夾內。
    
2. **命名規則（重要）**：
    
    - **全英文小寫 + 底線/連字號**（**切勿使用中文或空格**，避免網址產生亂碼）。
        
    - 建議格式：`品牌/簡稱_品名.jpg`
        
    - **範例**：
        
        - 華陽白咖啡 ➔ `oriental_coffee.jpg`
            
        - HETRAS 除臭劑 ➔ `hetras_deodorant.jpg`
            
        - Godiva 朱古力 ➔ `godiva_masterpiece.jpg`
            

### 步驟 2：建立 `my_posts.txt` 文字檔

在你的 `import_use/` 資料夾內開啟（或新建）一個 **`my_posts.txt`** 純文字檔。

#### ❓ 文字檔要唔要排版？

- **答案：要！而且請「原汁原味」排版！**
    
- 你平時在 WhatsApp / FB / IG 出 Post 時的空格、Enter 換行、所有彩色 Emoji（`✅`、`💰`、`☕️`、`🇲🇾`）都**直接 Copy & Paste 進去**。
    
- 純文字檔 (`UTF-8` 編碼) 會 100% 保留所有顏色和圖案，完全不會像 Excel 一樣變形。
    

### 步驟 3：配合現有出 Post 格式（範例模板）

Plaintext

#### 📌 語法關鍵說明：

1. **`[IMAGE: 檔名.jpg]`**：放在文章第一行，告訴腳本這篇 Post 對應哪張圖片。
    
2. **`[CATEGORY: 分類]`**（可選）：告訴系統屬於哪個分類（如：`美味零食`、`家居生活`、`飲品特選`）。若沒寫預設為 `精選商品`。
    
3. **`💰價格`**：內文只要有寫 `💰69` 或 `💰158`，腳本會**自動抓取數字**作為商品售價！
    
4. **`===`**：文章與文章之間的分隔線。
    

### 步驟 4：執行一鍵匯入腳本

當你在 `my_posts.txt` 貼好 1 篇或多篇新 Post，並且相片已放入 `images/` 後：

1. 打開 VS Code 終端機（Terminal）。
    
2. 輸入以下指令並按 Enter：
    
    PowerShell
    
    ```
    node import-posts-with-images.js
    ```
    
3. **完成！** 腳本會自動完成以下三件事：
    
    - 自動上傳 `images/` 裡的照片至 Supabase Storage 圖床。
        
    - 自動提取商品名稱、價格與完整排版文案。
        
    - 自動寫入 Supabase 資料庫，並在網店前台即時上架！
        

### 💡 店主貼心 Tips：

以後有任何新貨要出 Post，你只需要重複 **「存圖改英文名 -> Copy Post 到 txt -> 跑指令」** 這三步，幾秒鐘就可以完美上架，完全擺脫手動拉 Excel 圖和格式跑樣的煩惱！

你可以先拿一篇最新的 Post 試跑一次，有任何疑問我隨時在線上支援你！
